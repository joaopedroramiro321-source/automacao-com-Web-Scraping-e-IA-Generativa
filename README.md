# automacao-com-Web-Scraping-e-IA-Generativa
Desenvolvi uma aplicação em Python que une coleta de dados da web e inteligência artificial para gerar resumos automáticos de conteúdo.

Como funciona:

 🔹 O usuário informa a URL de um site
 
 🔹 A aplicação faz o scraping do HTML com Requests
 
 🔹 O conteúdo é enviado ao modelo Gemini 2.5 Flash, que gera um resumo focado no texto da página
 
 🔹 Interface via terminal, com loop interativo para resumir vários sites em sequência

Foi uma ótima oportunidade para praticar integração entre bibliotecas de scraping e APIs de IA generativa, além de reforçar lógica de automação em Python.
